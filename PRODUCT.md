# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React 19, Vite 8, Tailwind CSS 4, @xyflow/react, Zustand 5, framer-motion 12

## Users

Professional music producers, sound designers, composers, and live performers (the "creative technical practitioner"). These users have deep knowledge of signal flow, plugin architecture, and MIDI/audio routing, and need a high-velocity environment that keeps up with their speed of intent.

## Product Purpose

A modular, visual audio/MIDI plugin hosting environment that runs as a standalone desktop application and as a hosted plugin inside DAWs, letting users construct complex signal chains and custom instrument/effect processors with fluid flow-state speed.

## Positioning

A precision creative instrument for expert users. Rather than hiding technical complexity or depth, it surfaces it beautifully. It focuses on visual clarity, tactile routing speed, and hardware-instrument responsiveness.

## Operating Context

Runs as a standalone desktop app (macOS, Windows, Linux) or hosted plugin (VST3, AU, CLAP) inside third-party digital audio workstations (DAWs). It is used in studios and live performance setups, often operated via keyboard shortcuts, MIDI controllers, and multi-display environments.

## Capabilities and Constraints

- Hosts VST3, AU, LV2, and CLAP plugins.
- Visual node-based graph editor utilizing `@xyflow/react`.
- Real-time audio rendering engine with parallel CV (Control Voltage) flow paths.
- Lua scripting and Sol2 bindings for automation.
- Requires low latency and absolute stability under heavy processing loads.

## Brand Commitments

- **Name:** Element (Kushview LLC)
- **Aesthetic:** High-agency, premium, clinical yet warm, precision-crafted dark interface that feels like high-end studio hardware.

## Product Principles

1. **Velocity of Thought:** The interface must minimize steps required to connect, route, and interact with plugins.
2. **Instrument Aesthetics:** The design must look and feel like a premium physical instrument, avoiding standard SaaS or generic web app patterns.
3. **Real-time Responsiveness:** Every control, connection drag, and level display must render with low cognitive load and tactile feedback.
