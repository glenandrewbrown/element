Element

Welcome to the Element installer.

Element is a modular plugin host that allows you to create complex audio and MIDI routing configurations. It can run as a standalone application or as a plugin inside your favorite DAW.

Clean Installation: This installer will automatically remove any existing Element installation (application and all plugins) before installing the new version. Your user presets and preferences will be preserved.

Components to be installed:

  • Element Application - Standalone application in /Applications
  • AU Plugins - For Logic Pro, GarageBand, and other AU hosts
  • VST3 Plugins - For Ableton Live, Cubase, and other VST3 hosts
  • CLAP Plugins - For Bitwig and other CLAP hosts
  • LV2 Plugins - For Ardour and other LV2 hosts

What will be removed:

  • Existing Element.app from /Applications
  • All Element plugins from system and user plugin folders

Note: Please close any DAWs or audio applications before proceeding to ensure a clean installation.
