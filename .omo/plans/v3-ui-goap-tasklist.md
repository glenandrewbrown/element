4. **Parity-vs-A** — no native feature silently lost; auditor marks present/partial/MISSING.
5. **Per-component gate** — Glen + Chromatic sign-off before a component counts as done.
6. **Lane independence** — if CF1 (M0) slips, M1 keeps moving. Never stall UI behind the crash.
7. **Scope guard** — ~10 specialised node editors stay BACKLOG; Perform/Module/rail-tree OUT;
   re-confirm with Glen before building any deferred item.
