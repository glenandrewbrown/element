## 5. Recommended install command (single shot)

```bash
# webview deps
cd webview && \
  npm i lucide-react @lottiefiles/react-lottie-player && \
  npm i -D vitest @vitest/ui @testing-library/react @testing-library/jest-dom @testing-library/user-event jsdom @playwright/test && \
  npx playwright install chromium && \
  cd ..

# optional but recommended macOS
brew install ccache

# verify
cd webview && npx tsc -b && npm run build && cd ..
cmake --build build-merged -j8 && cd build-merged && ctest --output-on-failure -j4
```

Total time: ~3 minutes incl. browser download. No human input required after `brew install` (ccache is silent).
