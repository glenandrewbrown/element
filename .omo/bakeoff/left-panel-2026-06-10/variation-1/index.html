VARIATION 1 — SEARCH-COMMAND
One-surface browser. Search is the only entry point. Facets collapse to chips — no stacked sections above the fold. Everything serves finding something fast.
Facet chips → one list
★ and ⏱ are toggle chips, not sections. Tap ★ to filter to favourites; tap ⏱ to sort by recency. The virtualized list is the only scroll surface. No nested scroll fight.
Category shape + colour inline
Every row shows the same ●▲◆⬡ glyph as the canvas block. The browser and the canvas speak the same language. Colour-blind users read shape, not just hue.
Drag affordance (⠿ braille dots)
The drag handle only appears on hover — rows stay clean at rest. Drag any row to the board; the board receives it as a new Block at cursor position.
Collapsed rail = 40px icon rail
Tapping the search icon reopens + focuses search. Tapping a category glyph reopens + pre-filters. Never a blank strip. ⌘1 or ⌘\ to toggle.
Component mapping
Header → ToolPalette header section. List → PluginList (already virtualized). Chips → FacetChips (exists, Fav/Recent already stored). Footer → MoleculesSection + BoardsSection (already collapsed by default). Rail → unify ToolPalette collapsed branch, delete AppShell.CollapsedRail.
