Option 1 — Mini-Graph Thumbnail · Design Rationale
What it shows
A scaled-down live snapshot of the container's internal graph — mini pill-nodes coloured by category, mini cables. Below a complexity threshold (~6 nodes) it renders the actual topology. Above the threshold it falls back to a category-coloured density bar (a sparkline of block complexity). This gives the user a spatial memory of "what's inside" without diving in.
Implementation cost
Moderate. The thumbnail is a static SVG snapshot generated from containerNodeCount + the container's block list (available from the graph store). It is NOT a live re-render of React Flow — that would be too expensive. It is regenerated on container save. The density-bar fallback is trivial: a flex row of coloured divs proportional to CPU contribution.
Trade-offs
Pro: spatial memory — users can identify containers by their topology shape. The thumbnail is the ONE thing that communicates "there's a real graph in here" without diving. Con: adds ~96px of height to the block (bigger footprint on the canvas). The block-height tension is real — mitigated by collapsing to the title tier on scroll-out or when zoom < 0.6.
