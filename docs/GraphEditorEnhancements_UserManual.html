Comment Boxes

Comment boxes help you visually organize groups of related nodes in your graph, similar to Unreal Engine Blueprints or Blender's frame nodes.

Creating a Comment Box

Select nodes you want to group, then press C

Node Alignment Tools

Create clean, organized layouts by aligning multiple selected nodes.

How to Use

1. Select multiple nodes (Shift+click or drag-select)
2. Right-click → Alignment submenu

Tip: Nodes automatically snap to a 20px grid when moved for cleaner layouts.

Minimap Navigation

A bird's-eye view of your entire graph for easy navigation in large projects.

Toggle Visibility

Press M to show/hide the minimap

Navigate

Click anywhere on the minimap to instantly jump to that location

Pan

Click and drag on the minimap to smoothly pan around

Selected Nodes

Selected nodes appear in orange for easy identification

Viewport

White rectangle shows your current visible area

Node Search

Quickly find and navigate to any node in your graph.

Open Search

Press Cmd+F (Mac) or Ctrl+F (Windows/Linux)

Navigation

KeyAction
↑ / ↓Move selection up/down
EnterSelect node and close search
EscapeClose search
ClickSelect and highlight node
Double-clickSelect node and close
Tip: Search is case-insensitive and supports partial matching. Type "verb" to find "Reverb".

Performance Indicators

Real-time visual feedback showing latency and signal activity for each node.

Latency Display

Shows plugin processing delay in milliseconds (or samples if sample rate unavailable). Appears in bottom-left of each node.

Activity Meter

Color-coded bar showing signal level:
Green = Normal | Yellow = Moderate | Red = High

Tip: Red activity indicators may suggest clipping. Check your gain staging!
